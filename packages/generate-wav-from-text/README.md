# Generate WAV from Text

Synthesizes a selected text file with Voicebox `POST /generate` and saves `<stem>.wav` next to the file.

## Dependencies

Voicebox running locally.

## How to use

Select a `.txt` or `.md` file in Finder → Quick Actions → **Generate WAV from Text** → pick a Voicebox profile. Writes `<stem>.wav` beside the file.
