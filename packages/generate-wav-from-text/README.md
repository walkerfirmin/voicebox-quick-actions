# Generate WAV from Text

Synthesizes a selected text file with the local MLX TTS server (port 8002) and saves `<stem>.mp3` next to the file. Does not use Voicebox's generate queue.

## Dependencies

Voicebox running locally.

## How to use

Select a `.txt` or `.md` file in Finder → Quick Actions → **Generate WAV from Text** → pick a voice. Uses MLX TTS on port 8002. Writes `<stem>.mp3` beside the file.
