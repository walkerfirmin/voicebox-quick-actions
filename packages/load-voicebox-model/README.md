# Load Voicebox Model

Lists downloaded models from `GET /models/status`, lets you pick one to load into memory, or unload the active model(s). Uses `POST /models/load` (with legacy `model_size` fallback) and per-model unload.

## Dependencies

Voicebox running locally.

## How to use

Run **Load Voicebox Model** from Services, pick a downloaded model to load, or choose **Unload model** to free RAM.
