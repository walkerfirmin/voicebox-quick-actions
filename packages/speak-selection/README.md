# Speak Selection

Reads the highlighted text aloud in a chosen Voicebox voice and plays it on your speakers. Does not save a file.

## Dependencies

Voicebox running locally.

## How to use

Select text → Services → **Speak Selection**. A Finder voice list appears (last voice is pre-selected). Audio plays via the local MLX TTS server on port 8002. Set `VOICEBOX_PROFILE` to skip the picker.
