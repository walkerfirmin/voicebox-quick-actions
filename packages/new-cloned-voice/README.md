# New Cloned Voice

Creates a new Voicebox voice profile from a selected audio clip and its matching `.srt` (timestamps stripped). If no SRT exists, Whisper transcribes the clip first.

## Dependencies

Voicebox running locally.

## How to use

Select an audio file (optional sibling `.srt`) → Quick Actions → **New Cloned Voice**. Enter a profile name in the Finder dialog.
